# Seguridad

## Uso responsable

Este repositorio contiene scripts de **auditoría, escaneo y pruebas de carga**.

- Usá las herramientas **solo** en sistemas propios o con **autorización escrita**
- No ejecutes escaneos ni ataques contra infraestructura de terceros
- Revisá cada script antes de ejecutarlo; algunos requieren permisos elevados

## Secretos

No commitees credenciales, IPs internas reales ni resultados de auditorías con datos sensibles.

## Reporte de vulnerabilidades

Si encontrás un problema en el código (no en targets de prueba), contactá al mantenedor via [GitHub Security Advisories](https://github.com/ghcetraro/business_security/security/advisories/new).
